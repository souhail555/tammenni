# طمّنّي 💚

تطبيق (iPhone + Android) بيطمّن العيلة على الأهل الكبار بالعمر.

## الميزات
- زر كبير «أنا بخير» + تذكير يومي الصبح
- أدوية مع تذكير يومي بوقتها + زر «أخدتها»
- زر طوارئ: رسالة SMS لكل أرقام العيلة + اتصال بأول رقم
- **ربط الموبايلات بكود عيلة من ٦ أحرف**: موبايل الأب بيعطي الكود، والأولاد بيكتبوه
- لوحة العيلة: حالة اليوم، آخر ٧ أيام، الأدوية، النشاطات، وكلها بتتحدّث مباشرة
- إشعار للأولاد لما يطمّن الأب، أو ياخد الدوا، أو يكبس طوارئ
- **تنبيه تلقائي من السيرفر** إذا ما طمّن قبل الموعد (حتى لو موبايله طافي)
- إذا ما في إنترنت، الطمأنة بتنحفظ وبتنبعت لما يرجع النت

بدون مفاتيح Supabase التطبيق بيشتغل على موبايل واحد بس (بدون ربط).

---

## التشغيل السريع (بدون ربط)
```bash
npm install
npx expo start
```
امسح الـ QR بتطبيق **Expo Go**، أو اكبس `w` للمتصفح.

---

## تفعيل ربط الموبايلات (مرة وحدة، حوالي ١٠ دقايق)

### ١. قاعدة البيانات (Supabase، مجاني)
1. اعمل حساب ومشروع جديد على supabase.com.
2. **SQL Editor** ← الصق كل محتوى `supabase/schema.sql` ← **Run**.
3. **Authentication ← Sign In / Providers** ← فعّل **Allow anonymous sign-ins**
   (حتى الكبير بالعمر ما يحتاج إيميل ولا كلمة سر).
4. **Project Settings ← API**: انسخ الـ URL والـ publishable key.
5. انسخ `.env.example` لملف اسمه `.env` وحط القيم فيه، وبعدين أعد تشغيل `npx expo start`.

### ٢. الإشعارات للأولاد (Push)
```bash
npm install -g eas-cli
eas login
eas init
```
- **أندرويد**: الإشعارات ما بتشتغل بـ Expo Go، لازم نسخة تطوير:
  `eas build --profile development --platform android`
  (وبتحتاج إعداد Firebase FCM من موقع Expo).
- **آيفون**: بدها حساب Apple Developer (٩٩$ بالسنة) لإشعارات الـ Push.

بدون Push، لوحة العيلة بتضل تتحدّث لحالها كل ما تفتح التطبيق.

## كيف شغّال من جوّا
| الملف | شو بيعمل |
|---|---|
| `App.tsx` | الشاشات، والمزامنة، وصندوق الرسائل اللي ما انبعتت |
| `src/cloud.ts` | الاتصال بـ Supabase: إنشاء العيلة، الانضمام بالكود، الأحداث، الإشعارات |
| `src/notify.ts` | التذكيرات المحلية (الدوا والصبح) |
| `supabase/schema.sql` | الجداول، والحماية (كل عيلة بتشوف بياناتها بس)، والإشعارات، والفحص كل ١٠ دقايق |
